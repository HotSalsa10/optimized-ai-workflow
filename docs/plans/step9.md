## 0. In plain words

**What step 9 does.**
- **This repo moves to `v0.8.0`**, in one session you open where its hooks are off, as step 8 planned. Then the warning line about the two GitHub merges whose messages lack their verdict line (a15ad31 and ecefab8) is cleared by a recorded setting.

## 6. Risks and known limits

- **The effort pick** (S16): a session opened at the picker's default runs the main session below Best results; README and the live test say so; no check enforces it yet.
- **MCP skills and built-in commands** (S6): Release 2.
- **The published-release comparison** waits (S8): a sync from a doctored copy still writes a matching lock, and the review and the owner's merge stay the locks (RISKS #2). "Ready to merge" reads no CI result, so a project with a CI-only check is never READY (A34's cost).
- **The live test** is one run: one example, one client version, a subscription sign-in, the web. Phone, a Console key, `!` lines, SessionStart's `clear`, Remote Control, the update and uninstall routes, and a Mac or Windows computer are not in it. It runs on a pre-release tag; the release equals it only for the files sync installs (S12's diff).
- **Hookless install sessions** (9.1, live session A, and every project's install or update) have write access to both repositories and no floor; what holds them is M079's exception (text, keyed to the owner's message) and the review of the install branch afterwards.
- **Pull requests in cloud sessions** depend on the GitHub tools the session offers (S15); without them the owner opens it by hand.
- **The project's workflow** belongs to the project (S7): nothing lints it once seeded, a change to it takes the full route, and that review is its only lock. A cloud session may not be allowed to push a workflow file (Q5). A project whose checks all run locally is red in CI with exit 3 until fixed.
- **Live results in this repository** are outcomes only (S14).
- **The tested client is the newest.** A newer client can change behaviour before the next pin move (RISKS #3); the floor stays tested. The Fable marker on every main-session request at 2.1.332 is not explained (F13).
- **Windows and macOS** are not run for Release 1 (A27).
- **M080's home** is this repository's README, which a project does not receive; an owner reads it before installing.
- **Whether the method beats plain use is not known in Release 1** (S19): v1 ships on its design and its proofs; the measurement is Release 2's first item, and its result may simplify the method before the owner's projects move to it.
